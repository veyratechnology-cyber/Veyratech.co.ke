## 📊 Support vs. New Work

Help clients understand what's support vs. new work:

### ✅ Covered by Support:
- Bug fixes
- Issues with existing features
- Questions about functionality
- Help using the system
- Performance problems
- Minor adjustments

### 💰 Requires New Quote:
- New features
- Major changes
- Additional functionality
- New integrations
- Significant modifications
- Work outside original scope

**Rule:** If it's fixing something that should work, it's support. If it's adding something new, it requires a quote.

## 🎓 Training Clients

### What to Include in Issue Reports:

**Good Example:**
```
Subject: [HIGH] Website form not submitting

Description:
- What: Contact form on homepage not working
- When: Started today around 2 PM
- Error: "Failed to submit" message appears
- URL: https://example.com/contact
- Steps: Fill form, click Submit, see error
- Browser: Chrome on Windows
- Screenshot: Attached
```

**Poor Example:**
```
Subject: Help!

Description:
It's not working.
```

### Teach Clients to Include:
- ✅ What they were trying to do
- ✅ What happened instead
- ✅ Error messages (copy exact text)
- ✅ Screenshots if possible
- ✅ URL where issue occurs
- ✅ When it started
- ✅ Priority level
